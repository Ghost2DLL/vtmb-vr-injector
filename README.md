First Playable Release Available!

The first playable version of BloodlinesVR is now available!

After two weeks of development, Vampire: The Masquerade – Bloodlines can finally be experienced in immersive stereoscopic VR using Meta Quest 3 and Virtual Desktop.

Download BloodlinesVR – First Playable Release

This is an early experimental build. Performance, rendering and VR interactions still need a lot of work, but it’s a first step towards making the entire game playable in VR.

Feedback and bug reports are welcome!
