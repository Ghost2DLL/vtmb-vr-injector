Ghost2DLL — VTMB VR Injector

Experimental PC VR injector for Vampire: The Masquerade – Bloodlines

Ghost2DLL (BloodlinesVR) is a hobby project to bring the original Vampire: The Masquerade – Bloodlines to PC VR without rebuilding the game in a different engine.

First Playable Release — Available Now!

The first experimental playable build is available to download. After two weeks of development, Bloodlines can be experienced in immersive stereoscopic VR using Meta Quest 3 and Virtual Desktop.

Tested Configuration

• Game: Vampire: The Masquerade – Bloodlines (Steam)
• Patch: Unofficial Patch 11.5
• Language: Italian translation mod installed during testing
• Headset: Meta Quest 3
• PC VR connection: Virtual Desktop

Other configurations have not yet been fully tested.

Download and Installation

1. Install a legitimate PC copy of Vampire: The Masquerade – Bloodlines.
2. Install Unofficial Patch 11.5. This is the version used for development and testing; compatibility with version 12.0 has not been confirmed.
3. Download the injector package from the BloodlinesVR release page.
4. Follow the installation and launch instructions included with that release package. Do not replace existing game or Virtual Desktop settings unless the instructions explicitly require it.

Unofficial Patch 11.5: This is a separate project by Wesp5 and its contributors. If an archived original installer is provided in this repository’s Releases, it is offered separately from Ghost2DLL and remains the work of its original authors.

Current Limitations

• Performance and FPS need significant improvement.
• Some pre-rendered sequences and transitions are not yet properly handled in VR.
• Certain interactions, particularly in-game computers, still require keyboard input.
• VR controls and interactions need further refinement.
• Full-game stability and compatibility have not yet been established.

How It Works

Instead of moving Bloodlines to another engine, Ghost2DLL aims to act as a VR injection layer for the original game:

Vampire: The Masquerade – Bloodlines
                 |
                 v
         Original game engine
                 |
                 v
         Ghost2DLL VR Injector
                 |
                 v
               OpenXR
                 |
                 v
                PC VR

The goal is to preserve the original atmosphere, story and gameplay while adapting the experience for virtual reality.

Development Priorities

• Improve frame rate, rendering performance and visual clarity.
• Address stereoscopic rendering issues and problematic sequences.
• Reduce or eliminate the need for keyboard and mouse.
• Improve VR controller mapping and in-game interactions.
• Explore more natural first-person combat, aiming and melee interactions.
• Work towards a complete playthrough without VR-specific blockers.

These are development goals, not promises of completed features or a release schedule.

About the Project

Ghost2DLL is a personal hobby project developed in my spare time. I’ve always loved Vampire: The Masquerade – Bloodlines, and I think its atmosphere and world could be fantastic in VR.

I’m learning and experimenting as I go. Updates may be irregular, but I’ll share progress as development continues.
